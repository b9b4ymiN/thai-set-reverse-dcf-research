# Primary 100-stock SET100 bundle

This is the primary data bundle for the Reverse DCF backtesting system.

## Configuration
- **Universe Size**: 100 tickers (SET100)
- **Data Source Strategy**: Scraping-first priority (StockAnalysis.com) with Yahoo Finance fallback.
- **Coverage Split**: 85 tickers from primary source, 15 from fallback.

## Usage
Referenced as the source of truth for all backtest pipeline runs.
