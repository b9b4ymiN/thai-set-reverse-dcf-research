คำถามหลักที่งานนี้ต้องตอบ

งานนี้ไม่ได้ถามแค่ว่า “หุ้นตัวไหนขึ้น” แต่ถามว่า Reverse DCF ช่วยให้เราเลือกหุ้นไทยได้ดีขึ้นจริงไหม เมื่ออ่านราคาหุ้นเป็นความคาดหวังของตลาด แล้วเทียบกับ fundamentals ที่บริษัทส่งออกมาทีละไตรมาส

คำตอบสั้นแบบคนทั่วไป

คำตอบที่ต้องพิสูจน์คือ:

  1. ราคาหุ้นกำลัง “สะท้อนความคาดหวัง” อะไรอยู่
  2. fundamentals ล่าสุดบอกเรื่องเดียวกันหรือไม่
  3. เมื่อ fundamentals เปลี่ยน เราควร “ถือ / เข้า / ออก” หุ้นตัวไหนในพอร์ต
  4. ถ้าทำแบบมีวินัยรายไตรมาส ผลลัพธ์ดีกว่าตลาดหรือไม่

อ่านหน้านี้อย่างไร

ลำดับที่ดีที่สุดสำหรับคนทั่วไปคือ:

  1. ดูคำถามและคำตอบสั้นก่อน
  2. ดู stock highlights เพื่อเห็นภาพเร็วว่าหุ้นไหนเด่น หุ้นไหนกำไรมาก และหุ้นไหนพลาด
  3. เลื่อนลงไปอ่าน quarterly timeline ทีละรอบ เพื่อดูว่า “fundamental เปลี่ยนตรงไหน แล้วพอร์ตตอบสนองอย่างไร”
  4. ถ้าต้องการรายละเอียดเชิงวิธีวิจัย ค่อยไปต่อที่หน้า thesis / research / backtest

สิ่งที่ quarterly timeline ต้องทำให้ชัด

ในแต่ละไตรมาส คนอ่านต้องเห็นให้ครบว่า:

  • พอร์ตถือหุ้นอะไรอยู่บ้าง
  • มีหุ้นอะไรเข้าใหม่
  • มีหุ้นอะไรออกจากพอร์ต
  • ใช้งบชุดไหนในการตัดสินใจ
  • signal ที่เปลี่ยนเกิดจากอะไร
  • สุดท้ายไตรมาสนั้นหุ้นไหนเด่นสุด กำไรมากสุด และขาดทุนมากสุด

หลักการเขียนเอกสารหน้านี้

  • ใช้ภาษาคนทั่วไปก่อน
  • เริ่มจาก “สิ่งที่ต้องพิสูจน์” ไม่ใช่เริ่มจากศัพท์เทคนิค
  • ถ้ามีสมการหรือคำอธิบายเชิงลึก ให้โยงไป appendix หรือ thesis
  • ถ้า output final ยังไม่พร้อม ให้บอกตรง ๆ ว่าตอนนี้เป็นโครงสร้าง/ผลล่าสุดที่มีใน repo ไม่ใช่ผลสรุปสุดท้าย

สิ่งที่ยังต้องรอจาก upstream lanes

  • dataset 100 หุ้นแบบ multi-source ที่ใช้ scraping เป็นแกน
  • ผล backtest final แบบ Damodaran 2 case
  • กฎ stop-loss และ “แพ้เกิน 2 buy rounds แล้วห้ามซื้ออีก”
  • attribution ที่บอกให้ชัดกว่านี้ว่าหุ้นถูกคัดเข้า/ออกเพราะ metric ไหนเปลี่ยน
สิ่งที่หน้าเว็บนี้ตอบให้ได้ทันที
  1. เรากำลังพิสูจน์อะไร และคำตอบสั้นตอนนี้คืออะไร
  2. ไตรมาสไหนพอร์ตถืออะไร เข้าอะไร ออกอะไร
  3. หุ้นไหนเด่นสุด / กำไรมากสุด / ขาดทุนมากสุด
  4. ส่วนไหนยังต้องรอ output final จาก upstream lanes
  5. คำถามที่พบบ่อย (FAQ)

FAQ

คำถามที่พบบ่อย (Investor FAQ)

Reverse DCF คืออะไร?

คือการคำนวณย้อนกลับจากราคาหุ้นในตลาด เพื่อหาว่านักลงทุนกำลังคาดหวังการเติบโตของกำไรหรือกระแสเงินสดเท่าไหร่ แล้วจึงนำมาเทียบกับตัวเลขจริงที่บริษัททำได้เพื่อให้เห็นว่าหุ้นแพงหรือถูกเกินไปจากความคาดหวังนั้น

ทำไมต้องเน้นหุ้นใน SET100?

เพราะเป็นกลุ่มหุ้นที่มีสภาพคล่องสูงและมีการเปิดเผยข้อมูลพื้นฐานสม่ำเสมอเพียงพอที่จะนำมาสร้างโมเดลย้อนกลับ (Reverse) ได้อย่างน่าเชื่อถือเมื่อเทียบกับหุ้นขนาดเล็ก

พอร์ตลงทุนปรับเปลี่ยนทุกไตรมาสหมายถึงอะไร?

โมเดลจะทำการตรวจสอบงบการเงินล่าสุดที่ประกาศออกมาทุก 3 เดือน หากพื้นฐานเปลี่ยนไปจนทำให้ความคาดหวังในราคาหุ้นไม่สมเหตุสมผล พอร์ตจะทำการหมุนเวียนหุ้น (Rebalance) ทันที

ความเสี่ยงที่สำคัญที่สุดคืออะไร?

คือความถูกต้องและรวดเร็วของข้อมูล (Data Lag) รวมถึงความผันผวนของตลาดในระยะสั้นที่อาจไม่สะท้อนพื้นฐานทันที เราจึงต้องใช้การถือครอง 3-12 เดือนเพื่อรอให้ราคาตอบสนองต่อพื้นฐาน

  • stock-change attribution ที่ละเอียดกว่า signal summary ถ้าฝั่ง engine ส่งเหตุผลระดับ factor/metric ออกมาได้
  • บทสรุป thesis/public wording รอบสุดท้ายหลังเลข final นิ่งแล้ว
